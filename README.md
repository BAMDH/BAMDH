## Featured projects

**[Data Migration Platform](https://github.com/BAMDH/Data-Migration-Platform)**
Microservice pipeline for data migration and enrichment on Kubernetes, with services communicating over RabbitMQ and monitored with Prometheus and Grafana. *Contributions:* the regex-processing service (RabbitMQ consumer, metrics, unit tests), Helm charts and architecture decisions. `Python` `RabbitMQ` `Helm`

**[DNS Server](https://github.com/BAMDH/DNS-server)**
Distributed DNS server: C interceptor (RFC 1035), Python API, health-checker StatefulSet and React admin UI, with single, multi-value, weighted, round-trip and geo-based routing. *Contributions:* API and Firebase data layer, Helm charts. `C` `Python` `React` `Firebase`

**[Geo-aware Caching](https://github.com/BAMDH/Geo-aware-caching)**
Geolocation-aware DNS and caching system that routes users to the nearest zonal cache. *Contributions:* the cache-management module in C, including the LRU, LFU, FIFO, MRU and Random eviction policies. `C` `Kubernetes`

**[Kubernetes Network Infrastructure](https://github.com/BAMDH/Kubernetes-network-infrastructure)**
Infrastructure as code with Helm: public/private namespaces, custom nftables router, Apache-based ingress controller, NGINX backends and a FreeSWITCH SIP server. *Contributions:* Router, Helm charts and functional tests. `Kubernetes` `Helm` `nftables`

**[CrowdSpark Web](https://github.com/BAMDH/CrowdSparkWeb)** · **[CrowdSpark Android](https://github.com/BAMDH/CrowdSpark-Android)**
Crowdfunding platform with Angular web and native Android clients on a shared Firebase backend. `Angular` `Java` `Firebase`
